# Invasion of the Turkeys 🦃

A Thanksgiving wave shooter. The turkeys are invading Earth — defend it.

You hold a hay bale with a **cranberry cannon** that auto-fires. Turkeys swoop, dive, and drop stuffing bombs. Survive the waves, then face the boss turkey at the end of each level.

## Play it
Open `index.html` in any browser (phone or desktop) — no build step, no installs. Or serve the folder with any static file server.

## Controls
- **Move:** drag, hold the ◀ ▶ buttons, or use arrow keys / A / D
- **Dodge (dash):** double-tap ◀ or ▶, flick sideways on the field, double-tap an arrow / A / D key, press **Space**, or tap the gold **Dodge** button. You're untouchable mid-dash; watch the DODGE meter for the cooldown (0.50 s)
- **Gravy Bomb:** tap the bomb button to clear the screen (limited count)
- **Pause:** pause button. **Sound:** mute toggle (synthesized effects, no audio files)

## Levels & bosses
1. **Barnyard Landing** — Big Gobbler
2. **Pumpkin Patch Assault** — Pumpkin Patch Pete
3. **Autumn Forest Ambush** — Colonel Cornbread
4. **Harvest Night Raid** — The Stuffing Titan
5. **The Great Roost** — Emperor Gobblezilla

## Pickups
- **Corn** — bonus points
- **Cranberries** — temporary triple-shot
- **Pie** — extra life
- **Pumpkin** — shield
